# Sara Beauty — Salon de coiffure & esthétique

Site vitrine multi-pages prêt pour Next.js et Vercel. Identité visuelle rose gold & beige.

## Pages
- `/` : accueil / landing page
- `/services` : catalogue des prestations et tarifs indicatifs en MAD
- `/a-propos` : présentation du salon
- `/contact` : coordonnées et réservation WhatsApp

## Lancer en local
```bash
npm install
npm run dev
```
Puis ouvrir http://localhost:3000.

## Déployer sur Vercel
1. Créer un dépôt GitHub et y envoyer le contenu de ce dossier.
2. Dans Vercel, choisir **Add New → Project** puis importer le dépôt GitHub.
3. Garder les réglages Next.js par défaut et cliquer sur **Deploy**.
